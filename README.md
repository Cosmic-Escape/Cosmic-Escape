# CosmicEscape — Personal Website

Built with Next.js + TailwindCSS (TypeScript).

## Local dev
1. npm install
2. npm run dev
3. Open http://localhost:3000

## Build
npm run build
npm run start

## Deploy
Deploy to Vercel (recommended) or any container host (Dockerfile included).
